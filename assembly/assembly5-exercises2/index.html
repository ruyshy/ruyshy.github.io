    Assembly 기초 연습문제 풀이2 - 명령어 개념 정리 퀴즈

    목차

    NASM 어셈블리어 명령어에 대한 이해도를 높이기 위한 연습문제입니다. mov, add, cmp, jmp, push, pop, call, ret 등 핵심 명령어와 스택 동작 구조를 객관식 퀴즈 형식으로 정리했습니다.

    1. 다음 중 mov 명령어의 올바른 사용 예시는?

    해설: [rbx + rcx]는 유효한 메모리 주소. mov [mem], [mem]은 금지라서 A는 틀림.

    2. add rax, 5 명령어 실행 후 결과로 올바른 설명은?

    해설: add는 기존 값에 값을 더하는 연산. 즉, rax += 5 와 같음.

    3. sub rax, 3 실행 전 rax가 10이었다면, 결과는?

    해설: sub는 뺄셈이므로 10 - 3 = 7이 됨.

    4. cmp rax, rbx의 의미는?

    해설: cmp는 뺄셈을 하되 결과를 저장하지 않고 플래그만 설정해서 조건 분기 판단에 사용.

    5. 조건 분기와 가장 밀접한 관계가 있는 명령어는?

    해설: 조건 분기(jz, jne 등)는 cmp로 플래그 설정 후 분기.

    6. 다음 중 무조건 점프하는 명령어는?

    해설: jmp는 조건 없이 무조건 지정한 주소로 점프함.

    7. push rax 수행 시 어떤 일이 일어나는가?

    해설: 스택은 위에서 아래로 쌓이기 때문에 push 시 RSP가 감소.

    8. pop rbx 수행 후 상태는?

    해설: pop은 RSP가 가리키는 값을 꺼내고, RSP는 증가.

    9. call func 명령어는 어떤 동작을 수행하는가?

    해설: call은 현재 RIP를 스택에 저장하고, 해당 함수로 점프.

    10. ret 명령어의 기능은?

    해설: ret은 call 시 push된 RIP 값을 pop해서 해당 위치로 복귀.
