GitHub Blog #8

## 목차 설정 방법

목차 설정 코드:

```markdown
toc: true
toc_sticky: true
```

`toc`는 목차, `toc_sticky`는 스크롤 따라가기

게시글 설정 예시:

```markdown
---
title: "GitHub Blog Start"
date: 2025-04-10
tags: [GitHubBlog]
toc: true
toc_sticky: true
---
```

게시글 전체 적용 예시 (_config.yml):

```yaml
  - scope:
      path: ""
      type: posts
    values:
      layout: single
      author_profile: true
      toc: true
      toc_sticky: true
      comments: true
      share: true
      related: true
      sidebar:
        nav: "main"
```
