GitHub Blog #6

여러 폰트 사이트가 있지만 저는 구글 폰트 사이트를 예시로 사용하겠습니다.

[https://fonts.google.com/](https://fonts.google.com/)

저는 Dongle Font(Dongle-Regular.ttf)를 사용하고 있습니다.

\_sass\minimal-mistakes\_variables.scss 추가

```scss
$dongle: 'Dongle', -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif !default;
```

수정해야 할 부분:

```scss
$global-font-family: $sans-serif !default;
$header-font-family: $sans-serif !default;
```

수정할 코드:

```scss
$global-font-family: $dongle !default;
$header-font-family: $dongle !default;
```

수정해야 할 부분:

```scss
/* system typefaces */
$serif: Dongle, Georgia, Times, serif !default;
$sans-serif: -apple-system, BlinkMacSystemFont, "Dongle","Roboto", "Segoe UI",
  "Helvetica Neue", "Lucida Grande", Arial, sans-serif !default;
$monospace: Monaco, Consolas, "Lucida Console", monospace !default;

/* sans serif typefaces */
$sans-serif-narrow: $sans-serif !default;
$helvetica: "Dongle", Helvetica, "Helvetica Neue", Arial, sans-serif !default;
```

위 처럼 Dongle를 추가해주었습니다.

\assets\css\main.scss 추가

```scss
@font-face {
    font-family: 'Dongle';
    src: url('/assets/fonts/Dongle-Regular.ttf') format('truetype');
    font-weight: normal;
    font-style: normal;
  }
```

> 블로그에 새로운 폰트를 적용했습니다.
> 
> 
> 그런데 막상 적용해보니, 폰트마다 고유한 크기나 두께가 다르다 보니 기존 스타일과 미묘하게 어긋나는 부분들이 보이더라고요.
> 
> 보기 좋은 글을 만들기 위해 폰트 스타일과 크기도 함께 조정했습니다.
> 
> 작은 차이지만, 이 변화가 블로그를 훨씬 더 자연스럽고 세련되게 만들어 줄 것 같아요.
